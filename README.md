📰 React News App

A simple and modern news application built with React and powered by NewsAPI.org.
Browse the latest headlines by category with pagination support.

🚀 Getting Started

Clone the repository

Install dependencies

Create an .env file in the root directory and add your NewsAPI key:

VITE_NEWS_API_KEY=YOUR_NEWS_API_KEY


Run the project

npm run dev

⚠️ Note

Due to NewsAPI limitations, the free plan may not work properly in production environments.
